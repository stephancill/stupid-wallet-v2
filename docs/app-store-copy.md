## Description

```
stupid wallet is a simple, self-custodial Ethereum wallet built into Safari.

Use dapps right where you browse. Connect, sign and send from Safari's toolbar popup without leaving the page, and approve each signature or transaction with Face ID or your device passcode.

KNOW WHAT YOU SIGN
- Clear signing decodes supported contract calls into readable actions and amounts
- Transaction simulation previews the tokens you will send and receive
- Every request shows the requesting site, network and account before you approve

YOUR PORTFOLIO
- ETH and tokens across Ethereum, Base, Arbitrum, Optimism and any EVM network you add
- USD values with 24-hour changes
- Track any ERC-20 token by name, symbol or address

SEND
- Send ETH and tokens to an address or ENS name
- Enter amounts in tokens or USD

WALLETS AND ACCOUNTS
- Create or import multiple wallets, each with as many accounts as you need
- Import a recovery phrase or private key, or add an address as watch-only
- Keys are stored in the iOS Keychain on this device and never leave it

NETWORKS
- Works with any EVM chain
- Use the default RPC or set your own endpoint per network

No accounts, no sign-up and no analytics.
```
